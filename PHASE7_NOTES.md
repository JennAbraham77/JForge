# WebForge Phase 7 — Honey & Cocoa UI refresh

This release builds on Phase 6. The login page remains split-screen, and the dashboard and editor receive a cohesive pastel-yellow/brown redesign.

## Changes
- Soft decorative dashboard hero, warm cards, and subtle hover animations.
- Rounded, tactile project cards and component buttons.
- Pastel component library, template picker, inspector, and dotted editor workspace.
- Responsive adjustments for smaller screens.
- Existing authentication, database storage, website components, font controls, and export code are retained.

## Run
1. Copy `server/.env` from your working Phase 6 folder.
2. In the project root: `npm run install:all`
3. Then: `npm run dev`
4. Visit http://localhost:5173

This is a styling-focused release. No database migration is required.
